### 流程说明

| 步骤 | 关键操作 | 输出 |
|------|---------|------|
| 1. 初始化项目 | `haohan-cli create xxxui` | 项目脚手架 |
| 2. 安装依赖 | `npm install` / `yarn` | node_modules |
| 3. 配置项目 | 修改 `package.json` 的 name/platform | 项目标识 |
| 4. 开发项目 | 编写页面、生成接口 | 功能代码 |
| 5. 执行命令 | `npm run hhI18next` | 路由ID、国际化key |
| 6. 开发完成 | git commit / push / merge | 代码合入 |

## 1. 初始化项目

### 1.1 安装 haohan-cli

```
npm install haohan-cli -g --registry=http://120.76.194.61:4000

```

### 1.2 创建项目

```
haohan-cli create xxxui

```

## 2. 安装依赖环境

```
npm install
或者
yarn

```

## 3. 配置项目环境

### 3.1 修改 package.json 中的的 name 和 platform 字段

```json
{
  "name": "xxxui", // 改成你自己的ui名称，例如：userui , moui
  "platform": "xxx" // 改成这个项目属于的平台，例如：ERP、CRM、SCM等
  // 其他配置...
}
```

## 4. 开发项目

### 4.1 国际化语法

```tsx
import i18next from '@haohan/utils/es/hhI18next';

// 中文
i18next.t('操作');

// 英文
i18next.tEn('English');
```

### 4.2 接口文件生成

```
npm run openapi
```

## 5. 执行命令

### 5.1 生成项目标准的配置文件

```
npm run hhI18next //给路由增加id,给国际化文本增加key
```
