## 1. 环境准备

### 1.1 安装 Node.js

要求 Node.js >= 10.0.0，建议 14.x 或者 16.x。

```bash
node -v   # 确认版本
```

### 1.2 配置私有 npm 仓库

项目依赖 `@haohan/*` 系列私有包，需先配置 registry。

在项目根目录创建 `.npmrc`：

```ini
registry=http://120.76.194.61:4000
```

或在安装时手动指定：

```bash
yarn add <package> --save --registry=http://120.76.194.61:4000
npm i <package> --save --registry=http://120.76.194.61:4000
```

### 1.3 安装依赖

```bash
npm install
# 或
yarn
```

### 1.4 修改 package.json 中的 name 字段

在 `package.json` 中，将 `name` 字段修改为 `你自己的ui名称`，例如：

```json
{
  "name": "userui", // 例如：userui , moui
  "platform": "ERP" // 平台名称必须例如：ERP、CRM、SCM等
  // 其他配置...
}
```

## 2. 项目启动

```bash
# 启动开发服务器（默认端口 8080，含 Mock 数据）
npm start

# 连接开发环境真实 API（推荐日常开发使用）
npm run start:dev
```

启动后访问：`http://localhost:8080/ui/`

> **说明：** 项目使用了 `hash` 路由模式，base 路径为 `/ui`（取自 `package.json` 的 `name` 字段）。

## 4. 新建页面（完整步骤）

### 4.1 配置路由

在 [config/routes.ts](config/routes.ts) 中添加路由：

```ts
{
  path: '/myModule',
  name: '我的模块',
  icon: 'smile',     // Ant Design 图标名
  component: './myModule/Index',
  id: 'ui-xxxx',//必须而且唯一，可以使用命令生成和自定义
},
```

页面主文件 `src/pages/myModule/Index/index.tsx` 的标准模板：

```tsx
import { useMemo } from 'react';
import {
  HhButtonModal,
  HhKeepAlive,
  HhPageFlexColumn,
  HhProSearch,
  HhTable,
  HhTitleRow,
} from '@haohan/ui';
import { useHhTable, useHhProSearch } from '@haohan/hooks';
import { MyApiGetPageList } from '@/services/MyModule/MyApi';
import getColumn from './config/columns';
import getSearchItems from './config/searchItems';
import AddModal from './components/AddModal';

const initialValues = {};

const MyModuleIndex = () => {
  const {
    dataSource,
    pageIndex,
    setPageIndex,
    pageSize,
    setPageSize,
    onLoadMore,
    onLoadAll,
    isLoading,
    total,
    getTableData,
    startRetrieveData,
  } = useHhTable({ initData: [] });

  const { actions, proSearchForm, proSearchData, proSearchDataRef } = useHhProSearch({
    initialValues,
  });

  // 获取列表数据
  const getList = async (queryParams?: any) => {
    const params = {
      pageIndex,
      pageSize,
      ...proSearchDataRef.current,
      ...queryParams,
    };
    getTableData(MyApiGetPageList(params));
  };

  const columns = useMemo(
    () => getColumn({ startRetrieveData: () => startRetrieveData(getList) }),
    [],
  );

  const searchItems = useMemo(
    () => getSearchItems({ proSearchData, actions }),
    [proSearchData, actions],
  );

  return (
    <HhPageFlexColumn>
      {/* 页面标题 */}
      <HhTitleRow autoTitle title="我的模块" />

      {/* 搜索区域 */}
      <HhProSearch
        actions={actions}
        form={proSearchForm}
        queryRequest={getList}
        searchItems={searchItems}
        keywordPlaceholder="请输入关键字搜索"
        pageSize={pageSize}
        pageIndex={pageIndex}
        setPageSize={setPageSize}
        setPageIndex={setPageIndex}
      >
        {/* 操作按钮区域 */}
        <HhButtonModal Components={AddModal} onOk={getList}>
          新增
        </HhButtonModal>
      </HhProSearch>

      {/* 表格区域 */}
      <HhTable
        tableProps={{ isLoading }}
        hasSet={true}
        dataSource={dataSource}
        column={columns}
        pageIndex={pageIndex}
        onLoadMore={onLoadMore}
        total={total}
        onLoadAll={onLoadAll}
      />
    </HhPageFlexColumn>
  );
};

// 使用 HhKeepAlive 包裹实现页面缓存
export default () => {
  return (
    <HhKeepAlive>
      <MyModuleIndex />
    </HhKeepAlive>
  );
};
```

## 5. 接口调用（Services）

接口文件位于 `src/services/` 下，按模块分目录组织。（**使用 openapi 命令生成，无需手动新增接口文件**）

1. 执行生成命令：

```bash
npm run openapi
```

生成的代码会出现在 `src/services/MyModule/` 目录下。

## 7. 国际化

项目使用 `@haohan/utils` 提供的 `hhI18next` 进行国际化。

### 使用方式

```tsx
import i18next from '@haohan/utils/es/hhI18next';

// 中文
i18next.t('操作');

// 中英文对照
i18next.tEn('English');
```

### 国际化脚本

```bash
# 一键执行完整国际化流程
npm run hhI18next
```
